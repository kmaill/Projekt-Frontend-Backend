# Projekt-Frontend-Backend
Projekt Frontend/Backend - SpaceSync

# Backend
Uruchomienie backendu:

```bash
cd backend
```

# Windows
```bash
.\mvnw.cmd spring-boot:run
```

# Linux/MacOS
```bash
./mvnw spring-boot:run
```

# Frontend
Uruchomienie frontendu:

```bash
cd frontend
```

```bash
npm install
```

```bash
npm run dev
```
